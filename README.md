# C++ Typing Speed Test

A C++ console-based Typing Speed Test that measures typing speed (WPM), accuracy, and completion time.

## Features
- Easy, Medium, and Hard difficulty levels
- Random sentences for typing practice
- Words Per Minute (WPM) calculation
- Typing accuracy calculation
- Correct character counting
- Separate high scores for each difficulty
- High scores saved using file handling
- Replay option

## Technologies Used
- C++
- File Handling
- Random Number Generation
- Time Calculation

## How to Run
Compile the program:

```bash
g++ main.cpp -o typingtest
```

Run it on Windows:

```bash
.\typingtest.exe
```
